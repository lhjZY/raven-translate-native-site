# ADR 0001：由私有 App 仓库触发公开安装包同步

- 日期：2026-10-18
- 状态：采纳

## 背景

App 源码仓库私有，Release 附件对官网匿名访客不可见。官网是独立静态仓库，已通过 main 推送触发 GitHub Pages 部署。需要让发布动作同步安装包和官网版本，而不暴露 App 源码。

## 决策

App 的 `release.published` 工作流读取自身附件，用仅限官网 Contents 写权限的令牌写入公开 Release。同步脚本由官网仓库的可信 main 维护，App 的默认令牌只读且不进入官网仓库 Secrets。公开说明由允许公开的版本、架构和校验值生成，不复制私有发布正文。

发布采用草稿、上传校验、公开下载校验、修改官网、提交推送的顺序。官网记录 `website/release.json`，通过语义版本比较防止旧版本覆盖。相同版本不同二进制视为冲突，禁止静默替换。

## 结果与边界

官网继续生成静态链接，无运行时 GitHub API 依赖。失败时保留旧入口，可能留下可重跑完成的草稿。私有仓库发布权限同时意味着公开该版本 DMG 的权限。细粒度令牌到期需轮换，未来若改用 GitHub App，可替换认证而保留流程。

当前契约限 arm64 / macOS 26+。签名、公证、平台支持和人工产品更新日志分别维护；这些能力变化时必须显式更新分发契约。取消私有源码约束或改用其他安装包存储服务时重新评估此决策。
